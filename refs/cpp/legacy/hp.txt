# HP aCC C++ demangling corpus.
#
# Format: one `<mangled><TAB><expected>` pair per line. `#` starts a comment.
# A line whose two fields are equal is a name that must not be claimed as C++.
#
# Provenance: hand-authored for this repository from the HP aCC grammar as
# implemented by libiberty's HP demangler (`libiberty/cplus-dem.c`, GCC 8.5.0,
# LGPL-2.1-or-later, consulted read-only as a behavioural reference and not
# vendored), and cross-checked symbol by symbol against that demangler. No GPL
# source, test case or generated output is copied here: the names below are
# encoding facts and the expected text is this crate's pinned spelling (see
# `refs/cpp.md`).
#
# HP aCC is cfront-derived and shares the ARM grammar, so only names that carry
# an HP production are listed here: a `X` template spec, an `S`/`U`/`A`
# template argument, an alternate entry point suffix `_<digits>`, or a special
# name that encloses one of them. A name the other legacy dialects read the
# same way is claimed by them first and lives in `gnu-v2.txt`, `arm.txt` or
# `edg.txt`.
#
# Normalisation applied to this crate's spelling, all documented in
# `src/cpp/legacy.rs`:
#
# - template arguments are separated by `, ` instead of `,`;
# - an encoded template base is decoded, where the reference appends the raw
#   encoding (`3baz__XSP5` is `baz<5>`, not `3baz<5>`);
# - no trailing comma is printed where the reference emits one after a type
#   argument that carries its own template spec (`foo<bar<6>>`, not
#   `foo<bar<6>,>`);
# - a destructor of a template-id class names the plain last component
#   (`bar::baz<5>::~baz`), where the reference repeats the argument list;
# - an unnamed function-pointer parameter prints its full declarator
#   (`void (*)(int, void)`);
# - a virtual table prints as `<type> virtual table`.
#
# Every line must demangle byte for byte; the corpus test fails on any
# mismatch, so coverage can only grow.
