# GNU v2 legacy C++ demangling corpus.
#
# Format: one `<mangled><TAB><expected>` pair per line. `#` starts a comment.
#
# Provenance: hand-authored for this repository from the GNU v2 grammar as
# documented in libiberty (`libiberty/cplus-dem.c`, GCC 8.5.0, LGPL-2.1-or-
# later, consulted read-only as a behavioural reference and not vendored), and
# cross-checked symbol by symbol against that demangler. No GPL source, test
# case or generated output is copied here: the names below are encoding facts
# and the expected text is this crate's pinned spelling (see `refs/cpp.md`).
#
# Names that GNU v2 rejects but another legacy dialect accepts live in
# `arm.txt` and `edg.txt`; every line here must be claimed as GNU v2 or not at
# all.
#
# Normalisation applied to this crate's spelling, both documented in
# `src/cpp/legacy.rs`:
#
# - an unnamed function-pointer or member-pointer parameter prints its full
#   declarator (`void (*)(void)`, `void (foo::*)(void)`); the historical
#   demangler prints ` (*)(void)` and ` (foo::)(void)`.
# - the `e` ellipsis is separated by `, `.
#
# Every line must demangle byte for byte; the corpus test fails on any
# mismatch, so coverage can only grow.
