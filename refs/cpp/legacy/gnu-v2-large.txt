#
# Format: one `<mangled><TAB><expected>` pair per line. `#` starts a comment.
#
# Provenance: derived from the permissively licensed `gnuv2_demangle` crate
# 0.6.0 (MIT OR Apache-2.0), git b956763673c8a6a03370c52cae240a2874ec5c26.
# Its `tests/snapshots/*_cfilt_plain.snap` files record c++filt-compatible
# demanglings of five real GNU v2 symbol lists (`ff2`, `hit_and_run`,
# `most_wanted`, `parappa2`, `ty_july_first`) shipped in the crate's tests.
# Upstream: https://github.com/Decompollaborate/gnuv2_demangle
#
# Selection: unique `(mangled, expected)` pairs whose expected text differs
# from the input were normalised to this crate's pinned spelling (below) and
# demangled by this crate. 55,554 pairs were demangled upstream; 54,505 matched
# this crate byte for byte as `cpp::Dialect::GnuV2`. Of those, 2,740 are
# claimed by another scheme when every backend is enabled (Go `_._`, `_vt.`
# and `_<class>.<member>` names, plus Rust `_R` prefixes), leaving 51,765
# pairs that `Scheme::detect` also reports as C++ with all features enabled.
# Sorting by mangled name and taking 0-based indices 0, 34, 68, ... gives
# 1,523 pairs. Source hashes and exclusions are recorded in `refs/cpp.md`.
#
# Normalisations applied to the upstream text:
#
# - whitespace between consecutive template closing brackets is removed
#   (`> >` -> `>>`);
# - the `e` ellipsis is separated by `, ` (`int,...` -> `int, ...`);
# - array `new`/`delete` print `operator new[]`/`operator delete[]` without
#   the historical space.
#
# Excluded from the candidate set:
#
# - 1,040 symbols whose productions this crate rejects (member templates `H`,
#   squangling `B`, template parameter references `X`/`Y`);
# - 9 pairs whose upstream c++filt-compatible text is a historical defect:
#   4 member-function-pointer parameters whose return type c++filt moves after
#   the following argument, and 5 `_GLOBAL_$I$`/`_GLOBAL_.I.` names whose
#   qualified-class payload c++filt prints without the `global constructors
#   keyed to` wrapper;
# - 2,740 names claimed by another scheme when all backends are enabled, as
#   described above.
#
# Every line must demangle byte for byte; the corpus test fails on any
# mismatch, so coverage can only grow.
